# skillcheckup is deprecated

SkillDoctor was renamed to **SkillClinic** on 24 November 2026: the old name
collided with existing Claude skills called skill-doctor and with a PyPI
package of the same name.

Install the new package instead:

```
pip install skillclinic
skillclinic --demo
```

This package is only a pointer: installing it installs `skillclinic` and
running the old `skilldoctor` command hands over to the new tool.
The new home is <https://github.com/Dongdarealest/SkillClinic>.
